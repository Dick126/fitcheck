# FitCheck 使用手册

## 1. 怎么打开

| 场景 | 地址 |
|---|---|
| 部署电脑本机 | http://127.0.0.1:8000 |
| 同一 WiFi 的局域网设备 | http://192.168.1.100:8000（示例，以实际局域网 IP 为准） |
| 云服务器上线后 | http://服务器公网IP:8000（发给朋友用这个） |

## 2. 新手上路五步

1. **注册**：用户名（2–24 字符）+ 密码（≥6 位）+ 昵称；
2. **设置资料**：身高、性别、出生年份、目标（增肌薄肌/减脂/塑形）、器械（健身房/居家）、每周训练天数、训练时段、提醒时间；
3. **录入身体数据**：体重必填，体脂/骨骼肌/腰围选填，可随时增删，自动生成体重折线图；
4. **生成计划**：计划页点「生成我的计划」，系统按你的数据和目标算出每日热量与蛋白质/脂肪/碳水，DeepSeek 教练写一段个性化说明，并给出周一至周日的动作表；
5. **每日打卡**：今日页一键打卡，勾选当天计划动作并填组数/次数/重量，可加自定义项目（如“椭圆机 20 分钟”）、写心得、打心情/精力星级。

## 3. 圈子与朋友

- **创建圈子**：圈子页 → 创建 → 得到 6 位邀请码；
- **加入圈子**：朋友注册后，在圈子页输入你的邀请码；
- **互相看打卡**：好友动态里能看到圈友最近 14 天的公开打卡（动作、心得、心情），可点赞；
- **排行榜**：圈内按 7 天完成次数排序，展示连续打卡天数，前三名有 🥇🥈🥉；
- **隐私**：身体数据永远只有自己可见；每条打卡可选择「公开」或「仅自己」。

## 4. 提醒怎么生效

- 设置页填好提醒时间（如 07:00），并点「开启浏览器通知」允许通知；
- 到点且页面开着时，会弹系统通知 + 页面横幅提醒；
- 手机上建议把网页「添加到主屏幕」，并保持标签页在后台；
- 云服务器上线并配置 HTTPS 后，可升级为更强的离线推送（PWA）。

## 5. AI 与费用

- 计划生成和 AI 教练点评调用 DeepSeek 接口；
- 默认使用圈主（管理员）配置的 Key；**你可以在设置页填自己的 DeepSeek Key**，填了就用你的，留空就用圈主的；
- 圈主建议在 DeepSeek 开放平台设置**消费限额**。

## 6. 常见问题

- **手机打不开网页**：确认和电脑同一 WiFi；电脑防火墙是否允许 python 访问；校园/公司网络可能隔离设备，需改用云服务器。
- **通知没弹**：浏览器权限是否允许；页面（标签页）是否开着。
- **生成计划没有响应**：确认已保存资料、网络正常；AI 超时会自动退回规则版说明，不影响计划本身。
- **忘记密码**：当前版本暂不支持自助找回，请联系圈主（以后版本会加）。
- **数据会丢吗**：数据存服务器 SQLite；上线后每天凌晨自动备份，保留最近 14 份。
